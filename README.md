# 6SevenUI

> **A meme element library for developers.**

6SevenUI is an open-source collection of **meme-inspired UI elements, icons, animations, reactions, and web assets** built for developers.

## ✨ Features

* 🧠 Meme & brainrot elements
* ⚡ Easy to use
* 🎨 Web-ready assets
* 🧩 Reusable components
* 🌐 Built for modern websites

## 🛠️ Built With

`JavaScript` · `HTML` · `CSS`
